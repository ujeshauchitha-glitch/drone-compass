## 2026-10-13 — Gate S1 PASSED; Gate S2 FAILED (study stopped at Stage 2, per PLAN.md section 7)
* **Gate S1 passed**: checks (a)–(f) pass for the verified H16 tensors (and for the recalled set R). Two independent yield implementations (eigenbasis vs Liouville) agree to ~1e-15 on 200 directions. Primary anisotropy ΔΦ = 0.2057 (Φ from 0.3345 to 0.5402), far above the 1e-3 threshold. Richer ASSUMED models dilute it to ≈0.01 (R2, R3); relaxation at 1e7/s reduces it to ≈1.5e-3 (scan-based). See `results/stage1_*.csv`.
* **Gate S2 FAILED as pre-registered** (`results/stage2_gate.json`): K3orth, ε = 1, Poisson only. Gate condition 1: ratios of MC median error to CRB-predicted median error at the three large-N points = 14541, 25858, 45982 (needed 0.5–2). Gate condition 2: log–log slope = −0.033 (needed −0.5 ± 0.1). Thresholds unchanged.
* **Cause (diagnosed, not a coding error)**: the N5/N10 tensors are diagonal in the molecular frame, so the molecule has exact π-rotation symmetries and Φ(±nx, ±ny, ±nz) = Φ(n) (checked numerically: mirror images give identical counts to 4e-13). Any element set whose rotations are axis permutations (K2, K3orth) inherits this, giving a 4-fold *mirror* ambiguity (up to ~90° apart) on top of the polarity ambiguity. The global ML estimator picks a mirror image about half the time (log-likelihood of the mirror image is equal to within noise), so MC medians are dominated by this and cannot approach the *local* CRB. The CRB itself is also singular at the three coordinate axes for this set.
* **Exploratory diagnostic (NOT a gate result, added after the failure, labelled as such)**: a fixed generic non-orthogonal K = 3 set (rotation vectors (0.3, 0.5, 0.2) and (−0.4, 0.2, 0.6) rad) removes the ambiguity: ratios 0.934, 0.898, 0.893, slope −0.483.
* Unit test `test_mle_recovers_truth_near_crb` was changed from a single K3orth assertion to two cases: K3orth is `xfail(strict=True)` documenting the ambiguity, K3generic must pass. This changes a unit test, not a pre-registered gate threshold or gate configuration.
* **Decision needed from the study owner before continuing**: either (A) amend PLAN.md with a clearly labelled post-hoc amendment (Gate S2 evaluated on the optimised/generic K = 3 set, K3orth reported as a failed baseline and a core negative finding), or (B) stop here and report. Nothing past Stage 2 has been run.

## 2026-10-13 (later) — Amendments 1 and 1.1, selection, and an estimator bug
* **Amendment 1** (PLAN.md, commit 589e2dd, before any new run): owner-approved option A, selection rule, design/evaluation split, Gate S2′, non-collinear test, requirements-table additions. No threshold changed; K3orth stays FAILED Gate S2.
* **Amendment 1.1** (commit 264b28b, before any design run): a smoke test showed the grid-pair min-KL objective was blind to exact mirror pairs (K3orth scored 114.4 nats vs 278.1 for the generic set on the 600-point grid). Selection and reporting therefore use J_ref (continuous inner minimisation); the DE search still uses the grid-pair objective as a heuristic. K3orth scores J_ref = 0 as it should.
* **Design result** (`results/stage2_design.json`): K = 3 restarts J_ref = 3.998, 4.788, 1.420 → restart 1 selected (design grid); confirmation grid J_ref = 2.26 nats (< 10 nats, i.e. some >10° pairs are only moderately distinguishable at N = 10⁸). K = 2 stays exactly ambiguous (J_ref = 0). K = 4 (exploratory): J_ref ≈ 7.9×10⁴.
* **BUG (estimator), found by a diagnostic after Gate S2′ had passed**: `Sensor.mle` refined only the single best grid point. At very large N the likelihood peak is much narrower than the grid spacing (~2.5°), so the best grid point can lie in a wrong basin. Symptom: ambiguity-failure rate (error > 10°) plateaued at 2–3 % even at N = 10¹¹ for the selected set. Diagnosis: in all 6 failures at N = 10¹⁰ the log-likelihood at the estimate was lower than at the truth (by 183 to 8.3×10⁴), and multi-start refinement recovered the truth to 0.0°. So these were estimator failures, not physical ambiguity (contrast with K3orth, where the mirror image has equal likelihood).
* **Fix**: refine up to 4 well-separated (> 8°) top grid candidates and keep the best. After the fix, failure rate at N = 10¹⁰ and 10⁸ is 0 of 300 for the selected set. Regression test added (`test_mle_no_wrong_basin_at_large_N`).
* **Re-runs after the fix (same seeds, same thresholds):** `stage2_gate.py` (Gate S2 for K3orth and the exploratory diagnostic), `stage2_sprime.py` (Gate S2′, failure rates, Ren comparison), `stage2_requirements.py` (Monte-Carlo verification). The pre-fix S2′ result (ratios 0.983, 0.950, 0.985; slope −0.517) is superseded; both are noted here. The fix was prompted by the failure-rate diagnostic, not by a gate outcome (the S2′ gate had passed before the fix).
* **Results after the fix** (all from `results/`): Gate S2 (K3orth) still FAILED: ratios 14478, 25621, 51653, slope −0.013. Gate S2′ (selected set, fresh data) PASSED: ratios 0.971, 0.935, 0.937, slope −0.523. K3orth ambiguity failure rate ≈ 0.7 at every N. Selected set: failure rate 0 for N ≥ 3×10⁸ at ε = 1.
* **Addition (EXPLORATORY, not in Amendment 1, logged before it runs):** `experiments/stage2_failure_threshold.py` — Monte-Carlo curve of the ambiguity failure rate (error > 10°) on an extended N grid (10² … 10¹²), selected set only, ε ∈ {1, 0.1} and the three derived contrasts, fresh seeds `spawn_key=(8, …)`, to report the smallest N with failure ≤ 5 %. No gate depends on it.
* **Ren et al. investigation (Amendment 1 requires this for any disagreement > 10×)** — `results/stage2_ren_investigation.json`. With the K = 3 selected set and Ren's *optimised* signal, our CRB-based total photons for a 5° median error were 3.2×10⁸ vs their 3.94×10⁵ (~800×). Cause found: element count/coverage. With K ≥ 12 randomly oriented elements the total converges to 4.6×10⁶ (K = 1000), i.e. a factor 11.7 above their figure; for the *default* signal K = 1000 gives 6.8×10⁷ against their 5.3×10⁷–2.3×10⁸. A factor of ~12 remains for the optimised row and is **not tuned away**; plausible reasons (not tested): their unknown is a 1-D head angle at a known inclination, ours is a 2-D axis; their bound is information-theoretic with a uniform prior, ours is a local Cramér–Rao bound; their cell orientations are a specific retinal geometry.
* **Exploratory failure-threshold curve done** (`results/stage2_failure_threshold.json`, selected set, 300 trials/point): smallest N with failure rate ≤ 5 % — ε = 1: 3.2×10⁴; ε = 0.1: 3.2×10⁶; ε_R2 = 0.044: 3.2×10⁷; ε_relax(1e6) = 0.39: 3.2×10⁵; ε_relax(1e7) = 0.011: 3.2×10⁸ photons per element (grid resolution: half-decades).
* **Non-collinear test done** (`results/stage2_noncollinear.csv`): tilting the N10 frame by α = 5°/15°/30°/60° about (1,1,0)/√2 in the minimal model gives mirror separation (D = 10 nats at the weakest pair) at N_mirror = 4.6×10⁶ / 5.1×10⁵ / 1.2×10⁵ / 3.5×10⁴ photons, so the exact ambiguity depends on the shared frame; in the richer assumed model (NC-R2) the ambiguity survives at α = 15° (D_min = 5.9 nats < 10 at N = 10⁸; N_mirror = 1.7×10⁸) and needs 1.3×10⁷ (30°) / 8.5×10⁷ (60°) photons otherwise. Caveats: tilts are ASSUMED, D_min over pairs ≥ 10° apart also contains a local-resolution term, and at 60° the NC-R2 anisotropy has dropped to 0.0033.
